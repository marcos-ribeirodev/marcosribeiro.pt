Website Pessoal de Marcos Ribeiro
=================================

Descrição do Projeto:
---------------------
Este é o website pessoal de Marcos Ribeiro, desenvolvido com o objetivo de apresentar o seu percurso académico e profissional, os seus projetos, e permitir contacto direto através de um formulário.

Estrutura de Ficheiros e Pastas:
--------------------------------
index.php              -> Página inicial
sobre.php              -> Página "Sobre Mim" com carta de apresentação
perfil.php             -> Página "Perfil Técnico" com currículo, experiências e idiomas
portfolio.php          -> Página com portefólio de projetos
servicos.php           -> Redirecionada para "perfil.php" (perfil técnico)
contactos.php          -> Página de contacto com formulário funcional
componentes/           -> Inclui cabeçalho, rodapé e outros componentes reutilizáveis
lang/                  -> Ficheiros de idioma (pt.php e en.php)
style.css              -> Ficheiro principal de estilos
phpmailer/             -> Biblioteca PHPMailer para envio de emails
enviar.php             -> Script PHP para envio de emails via formulário

Funcionalidades:
----------------
- Website bilíngue (Português e Inglês)
- Layout responsivo adaptado a vários tamanhos de ecrã
- Formulário de contacto funcional com envio de email
- Design moderno e escuro com destaque para conteúdos pessoais
- Estrutura modular para fácil manutenção e expansão

Tecnologias Utilizadas:
------------------------
- HTML5, CSS3
- PHP
- PHPMailer (para envio de emails)
- FontAwesome (para ícones)
- Alojamento em Hostinger
